# cmd/shortener

В данной директории содержится код, который скомпилируется в бинарное приложение.

Рекомендуется помещать только код, необходимый для запуска приложения, но не бизнес-логику.

Название директории должно соответствовать названию приложения.

Директория `cmd/shortener` содержит:
- точку входа в приложение (функция `main`)
- инициализацию зависимостей (можно вынести в отдельный пакет `internal/app`)
- настройку и совместный запуск HTTP- и gRPC-серверов
- обработку сигналов завершения работы приложения

## gRPC

gRPC-сервер предоставляет методы `ShortenURL`, `ExpandURL` и `ListUserURLs`
из контракта [`proto/shortener.proto`](../../proto/shortener.proto).
По умолчанию сервер слушает `localhost:3200`. Адрес можно изменить через
`grpc_address` в JSON-конфигурации, флаг `-g` или переменную
`GRPC_ADDRESS`; приоритет источников совпадает с HTTP-конфигурацией.

Подписанные авторизационные данные передаются в metadata `authorization`.
При первом вызове `ShortenURL` или `ListUserURLs` сервер создаёт пользователя
и возвращает значение `authorization` в response metadata. Последующие запросы
могут передавать это значение как есть или в формате `Bearer <значение>`.
Настройка `ENABLE_HTTPS`/`-s` включает TLS одновременно для HTTP и gRPC.
`SERVER_READ_TIMEOUT` ограничивает установление gRPC-соединения,
`SERVER_WRITE_TIMEOUT` — выполнение unary RPC, а `SERVER_IDLE_TIMEOUT` —
время простоя соединения.

## Аудит запросов

Приложение может отправлять события аудита для успешного сокращения и раскрытия
URL через HTTP или gRPC. События имеют JSON-формат:

```json
{"ts":12345678,"action":"shorten","user_id":"12315134","url":"https://example.com/path"}
```

Файловый приёмник включается через `--audit-file` или `AUDIT_FILE` и пишет по одному JSON-событию на строку. Удалённый приёмник включается через `--audit-url` или `AUDIT_URL` и получает события методом `POST`.

Доставка аудита выполняется через фоновую очередь. Запрос ждёт только постановки события в очередь, а ошибки доставки логируются; успешный HTTP-ответ пользователю из-за них не откатывается.

## Внутренняя статистика

`GET /api/internal/stats` возвращает количество сокращённых URL и пользователей
в JSON-полях `urls` и `users`. Доступ разрешён, только если IP из заголовка
`X-Real-IP` входит в подсеть, заданную через `trusted_subnet`, `-t` или
`TRUSTED_SUBNET`. При пустой подсети эндпоинт отвечает `403 Forbidden` на любой
запрос. Некорректная непустая подсеть считается ошибкой конфигурации и не
позволяет запустить сервер.
